# Skill: Implement Dashboard Layer

Use this when adding or changing UI layer components.

## Steps

1. Read `docs/07_UI_SPEC.md`.
2. Use API payload only.
3. Do not calculate metrics in React components.
4. Show result surface and collection/freshness surface where applicable.
5. Show risks and invalidation for every judgment.
6. Show locked state for gated future features.
7. Add tests for current RS leader and momentum leader separation.

## Copy Guardrail

MVP UI must not say buy, sell, target price, expected return, high probability, or auto order.
